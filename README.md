ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОЕКТА (ДЛЯ ПРЕПОДАВАТЕЛЯ)

Проект: Система управления сотрудниками (Django + Django REST Framework + JWT)
Выполнил: [Кулебакин В.Ю.]

1. РАЗВЕРТЫВАНИЕ ПРОЕКТА
В папке проекта выполнить команды в терминале:
   python -m venv env
   .\env\Scripts\pip install -r requirements.txt

2. ЗАПУСК СЕРВЕРА
   .\env\Scripts\python.exe manage.py runserver

3. ИНТЕРАКТИВНАЯ ДОКУМЕНТАЦИЯ (SWAGGER / REDOC)
После запуска сервера интерактивная документация со всеми эндпоинтами доступна по адресам:
   - Swagger UI: http://127.0.0.1:8000/api/docs/swagger/
   - ReDoc: http://127.0.0.1:8000/api/docs/redoc/

4. ТЕСТОВЫЕ ПОЛЬЗОВАТЕЛИ И РОЛИ (ДЛЯ JWT / POSTMAN)
В базу данных уже встроены группы доступа («Администратор», «Смотритель») и пользователи для проверки прав:
   - Администратор (Полный CRUD): 
     Логин: api_admin / Пароль: AdminPass123!
   - Смотритель (Только метод перемещения /move_desk/): 
     Логин: api_watcher / Пароль: WatcherPass123!
   - Посетитель (Только просмотр каталога): 
     Логин: api_guest / Пароль: GuestPass123!

5. ЗАПУСК АВТОМАТИЧЕСКИХ ТЕСТОВ
В проекте написано 12 Unit-тестов, покрывающих старую HTML-логику, CRUD API, пагинацию, JWT и бизнес-логику рассадки сотрудников.
Запуск тестов:
   .\env\Scripts\python.exe manage.py test
